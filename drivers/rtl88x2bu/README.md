# RTL88x2BU driver area

This directory is a placeholder for the Realtek RTL88x2BU driver source or a vendor-adapted copy.

Typical layout:
- `rtl88x2bu/`
- `Kconfig`
- `Makefile`
- `hal/`
- `core/`
- compatibility patches

The actual driver should be added here or linked into the target kernel tree.
